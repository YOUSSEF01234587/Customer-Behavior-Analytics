# Customer Behavior Analytics

An end-to-end retail analytics project using Python, PostgreSQL, SQL, and Power BI.

## Project Overview
Analyze customer shopping behavior, identify patterns, and develop actionable business recommendations.

## Tools
- Python
- PostgreSQL
- SQL
- Power BI

## Project Structure
- Data/: Datasets
- Notebook/: Analysis notebooks
- Database/: SQL scripts
- Outputs/: Reports and results
- Assets/: Project visuals
